# nookplot

> nookplot is a Base-native agent coordination protocol that describes itself as an “internet for agents”: a network where AI agents publish signed knowledge artifacts, build reputation from useful work, coordinate through guilds/marketplaces/bounties, and earn or spend through the $NOOK economy. The project has a live website/docs surface and active official X narrative, but several product/token-economy claims still need hands-on and on-chain verification.

## Overview

- **Project:** nookplot
- **Ticker:** $NOOK
- **Chain:** Base
- **Contract:** `0xb233bdffd437e60fa451f62c6c09d3804d285ba3`
- **Official website:** [nookplot.com](https://nookplot.com/)
- **Docs:** [nookplot docs](https://nookplot.com/docs)

- **GitHub link shown on site:** [github.com/nookprotocol](https://github.com/nookprotocol) — GitHub API returned 404 at check time, so repo/org visibility needs verification.
- **Bankr project description:** “Decentralized network for agents to coordinate and earn by building knowledge.”
- **Fee/deployer context from Bankr API:** deployer `0xc0f1fb72fd0a7c0651d93f5b28c683a68d383073`; fee recipient `0x08e028f68f4891c57d8565fb968dcced005dddab`, linked by Bankr to X username `nookplot`.

The project is framed around three primitives:

1. **Knowledge:** agents publish reasoning traces, learnings, and tools as signed/citable objects.
2. **Reputation:** useful work is measured and reputation accrues by domain.
3. **Economy:** bounties, marketplace escrow, citation royalties, guild treasuries, mining rewards, credits, and $NOOK staking/rewards appear in the product narrative.

The official X account is active and posts concrete metrics/catalysts: 100-day milestone, Agent Forge public beta, mining/RLM trajectory rewards, Knowledge Graph v2, and cross-protocol mining.

Treat the product as **claimed + partially visible through website/docs/X**, not yet fully verified as installable/usable.

### Getting started / CLI claims

The getting-started docs claim agents can:

- install the CLI with `npm install -g @nookplot/cli`;
- initialize an agent project with `nookplot init my-agent`;
- register gaslessly on Base with `nookplot register --name "my-agent"`;
- publish content to IPFS and record it on-chain through the ContentIndex contract;
- run `nookplot up` for autonomous operation, skill sync, proactive scanning, and a live dashboard.

Important caveat: `@nookplot/cli` did not resolve through the NPM registry API during this check, so the install path needs re-testing from a clean environment or alternative registry/source.

### Smart contracts

The contracts docs claim 20 UUPS proxy contracts on Base, using OpenZeppelin 5.1 and ERC-2771 gasless meta-transactions. The named contract areas include:

- Identity: `NookplotForwarder`, `AgentRegistry`
- Content: `ContentIndex`, `KnowledgeBundle`
- Social: `InteractionContract`, `SocialGraph`
- Community/projects: `CommunityRegistry`, `ProjectRegistry`, `ContributionRegistry`, `BountyContract`
- Agent infrastructure: `RevenueRouter`
- Collaboration: `GuildRegistry`, `CliqueRegistry (legacy)`, `ServiceMarketplace`
- Economy: `NOOK Token`, `CreditPurchase`, `RewardPool`
- Mining: `MiningStake`, `MiningGuild`, `MiningRewardPool`

The docs give an example `AgentRegistry` address: `0x8dC9E1e6E3eED7c38e89ca57D3B444f062d8a1c9`. This should be verified on Basescan and cross-checked against live app/API contract registries.

### Mining

The mining docs say nookplot rewards **verified reasoning trajectories**, not raw compute. Claimed lifecycle:

1. Stake NOOK in `MiningStake`.
2. Open a challenge.
3. Work in a cognitive workspace where Python execs, LLM subcalls, and artifacts are logged.
4. Finalize the trajectory and hash action graph.
5. Submit the trajectory.
6. Verification checks structural, behavioral, answer-correctness, and optionally peer-audit layers.
7. Accepted trajectories accrue to epochs; users claim from `MiningRewardPool` via Merkle proofs.

This is a strong technical claim but needs hands-on verification: challenge listings, submission flow, verifier outputs, epoch roots, and reward claims should be checked directly.

### Economics

The economics docs describe an internal **credit** system:

- Agents receive starter credits.
- More credits are purchased using USDC via `CreditPurchase` on Base.
- Protocol actions deduct credits.
- Monthly subscriptions are priced in USDC.
- Agents can also earn credits through participation and weekly reward pools.

Action-cost examples shown in docs:

- Publish post: 1.25 credits
- Post reply: 0.90 credits
- AI code review: 1.50 credits
- Bounty claim: 0.50 credits
- Sandbox execution: 0.50 credits + 0.01/sec
- Vote: 0.25 credits
- MCP tool call: 0.25 credits
- Egress request: 0.15 credits
- Meta-transaction relay: 0.10–0.50 credits

Subscription tiers shown in docs:

- Free: $0
- Starter: $5/month
- Builder: $25/month
- Pro: $99/month

This indicates a product economy beyond pure token speculation, but the live conversion between credits, USDC, $NOOK demand, and holder value needs verification.

## Token role and accrual

### Claimed / documented roles

The $NOOK token appears in several roles across website/docs/X:

- **Staking:** homepage shows ~1.1B NOOK staked; docs say staking in `MiningStake` is required for mining eligibility and larger stakes earn higher multipliers.
- **Mining rewards:** accepted reasoning trajectories can accrue rewards and be claimed from `MiningRewardPool`.
- **Agent Forge / inference:** official X says Forge + inference are paid in $NOOK and users can earn it back through solving challenges or publishing knowledge.
- **Knowledge/coordination economy:** official narrative ties $NOOK to agents, guilds, knowledge publishing, services, and work settlement.
- **Credits / USDC:** docs emphasize internal credits and USDC purchases/subscriptions, so $NOOK is not the only economic unit.

### What is verified vs not verified

- **Verified from sources:** docs/X claim staking, mining, reward pools, credits, bounties, marketplace, and Forge payment/earning flows.
- **Needs verification:** actual live staking contract balances, reward emissions, claim flow, Agent Forge payment flow, and whether users can currently earn/claim $NOOK.
- **Not established:** token-holder revenue accrual. Bankr fee recipient / Doppler earnings should not be equated with holder revenue unless a contract or official source proves distribution.
