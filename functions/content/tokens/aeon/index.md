# AEON — aeon

> AEON is a Base token and open-source autonomous-agent framework associated with `@aeonframework` and Aaron Elijah Mars. The project frames itself as “the most autonomous agent framework”: a GitHub Actions-based system for recurring agent work, skill scheduling, monitoring, self-checking, and self-repair. The current market and X narrative is hot because the token has moved sharply, Bankr public API fee data shows rising Doppler fees, and the official account is pushing an ecosystem-map / AgentFi narrative.

## Overview

AEON sits at the intersection of three narratives:

- **Autonomous agent framework:** the GitHub repo describes an unattended agent system that runs on GitHub Actions instead of a local server or VPS.
- **Skill marketplace / agent operations:** the README lists 117 skills across research, dev/code, crypto/markets, social writing, productivity, monitoring, and meta-agent maintenance.
- **Bankr/Base token narrative:** the token is live on Base, listed by Bankr, and has public Bankr API snapshots for market, fees, LLM usage, tweets, and project metadata.

## Product and technology

AEON describes itself as a framework for unattended agent work. Instead of using an agent as an interactive coding/chat tool, AEON uses GitHub Actions as the always-on runtime.

README-backed product claims:

- Runs unattended on schedules.
- Uses GitHub Actions as zero-infrastructure runtime.
- Has persistent memory across runs.
- Supports reactive triggers, not just cron.
- Monitors its own output quality.
- Can self-heal or repair failing skills.
- Includes 117 skills across research, code, crypto, social, productivity, monitoring, and meta-agent categories.

Product surfaces listed by the Bankr public API:

- **aeon:** GitHub project for the autonomous agent framework.
- **SOUL.MD:** described as a way to build a personality for an agent by letting Claude Code / OpenClaw ingest data and build an “AI soul.”

### Technology claims that need hands-on verification

The repo and README support the existence of the framework, but this refresh did not run a local AEON instance. Claims to verify in a deeper pass:

1. Clone repo and run `./aeon` locally.
2. Open the dashboard on localhost and verify onboarding flow.
3. Configure a dummy skill and schedule.
4. Push to GitHub Actions and confirm it runs unattended.
5. Test a self-healing or skill-repair scenario.
6. Verify whether token or Bankr identity is required anywhere in the actual framework.

## Token role and accrual

Verified:

- `$AEON` is the Base token associated with the aeon profile on Bankr public API.
- The token has a main pool and fee recipient associated with `aeonframework` in Bankr discover.
- The Doppler fee endpoint returns fee share, claimable, claimed, lifetime earned, and daily WETH values.

Unverified / unclear:

- Whether token holders receive any direct share of fees.
- Whether the token gates access to the framework, products, skills, rewards, or deployments.
- Whether Bankr fee share maps to a token-holder accrual mechanism, a project treasury, a deployer/fee-recipient address, or another entity.
- Whether AEON token utility is implemented in the GitHub framework itself.

Conservative read: `$AEON` currently functions as a market/social/project token attached to the AEON framework and Bankr/Doppler pool fee data. Direct accrual should remain **unverified** until documentation or contract-state evidence proves it.
